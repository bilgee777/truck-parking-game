# 🚛 Truck Parking Game

A 3D truck driving and parking simulation developed with **Unity and C#** as my Computer Engineering graduation project.

The project focuses on vehicle physics, parking mechanics, player controls, camera systems, UI flows, and gameplay interaction.

## ⚙️ Technical Implementation

### Vehicle System

The truck movement system is implemented using Unity's **Rigidbody** and **WheelCollider** components. Vehicle behavior includes steering, motor torque, braking, and reverse functionality.

### Parking System

Parking areas use trigger-based detection to determine whether the truck has successfully reached the target parking position.

### Camera System

A follow-camera system tracks the vehicle during gameplay and provides an appropriate driving perspective.

### Input System

The project supports both keyboard and joystick input, allowing the vehicle systems to respond to different control methods.

### UI & Game Flow

The project includes multiple UI and gameplay states, including:

* Start Menu
* Player Profile
* Garage
* Gameplay Scene
* Parking objectives
